# Typed at the prompt by scripts/move-test after typed.txt, on GR-DOS only:
# files under two names, through SUBST, which MS-DOS 6.22's MOVE gets wrong
# (it deletes the file it is about to copy) and whose SUBST.EXE is not on
# the install. Its output is tests/move/expect-grdos.log, GR-DOS's own.
# Nothing here may change a file. Then where GR-DOS's MOVE is safer than
# 6.22's: a source it copies but cannot delete (B: is write-protected),
# whose copy it deletes, and a file it fails to replace (A: is too small),
# which it keeps.
CD \M\T19
C:\DOS\SUBST E: D:\M\T19
MOVE A.TXT E:\A.TXT
EL
MOVE E:\B.TXT D:B.TXT
EL
MOVE *.DAT E:\
EL
MOVE E:X.DAT,E:Y.DAT D:\M\T19
EL
MOVE DIR1 E:\DIR1
EL
C:\DOS\SUBST E: /D
== keys F F F F F F
MOVE B:\B.TXT D:\M\T19\SUB
EL
IF EXIST SUB\B.TXT ECHO The copy is still there.
COPY A.TXT A:\BIG.BIN > NUL
== keys y^M
MOVE ..\BIG\BIG.BIN A:\
EL
TYPE A:\BIG.BIN
DEL A:\BIG.BIN
