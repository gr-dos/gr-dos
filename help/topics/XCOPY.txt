Topic: XCOPY
Summary: Copies files, and directories with their subdirectories
Origin: MS-DOS 4.00
Group: command
Files: XCOPY.EXE

Syntax
  XCOPY source [destination] [/A | /M] [/D:date] [/P] [/S [/E]] [/V] [/W]

  source       The files to copy: a drive, a directory, or a file name,
               which may have wildcards (* and ?).
  destination  Where to copy them; the current directory if left out.
  /A           Copies only files with the archive attribute set, and
               leaves it set.
  /M           As /A, but clears the attribute of each file copied, so
               that the next XCOPY /M copies only files changed since.
  /D:date      Copies only files changed on or after the date, in the
               country's date format (MM-DD-YY in the US).
  /P           Asks (Y/N) before copying each file.
  /S           Copies the subdirectories too, but not empty ones.
  /E           With /S, copies empty subdirectories as well.
  /V           Reads each copy back to check it.
  /W           Waits for a key before it starts, so that you can change
               disks.

Examples
  XCOPY A:\*.* B:\ /S /E
    Copies everything on A:, with all its directories, to B:.
  XCOPY C:\WORK D:\BACKUP\ /M
    Copies the files of C:\WORK changed since the last XCOPY /M.

Exit status
  0  The files were copied.
  1  No files were found to copy.
  2  Stopped with Ctrl+C.
  4  Not enough memory or disk space, a bad drive name or syntax.
  5  A disk write error.

Notes
  When the destination does not exist and does not end in \, XCOPY asks
  whether it is a file (F) or a directory (D). End it with \ to say it is
  a directory. XCOPY reads as many files as fit in memory before writing
  them, so it is faster than COPY, but cannot copy between two disks in
  one drive: use DISKCOPY or COPY for that. Hidden and system files are
  not copied.
