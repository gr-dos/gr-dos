Topic: MORE
Summary: Shows text a screenful at a time
Origin: MS-DOS 4.00
Group: command
Files: MORE.COM

Syntax
  MORE < [drive:][path]filename
  command | MORE

  MORE takes no parameters: it reads its standard input, given with < or
  a pipe (|), and writes it to the screen.

Examples
  MORE < README.TXT
    Shows README.TXT, stopping after each screenful.
  DIR | MORE
    Lists a long directory a screen at a time.

Notes
  After each screenful MORE shows -- More -- and waits for a key; any key
  shows the next screenful, and Ctrl+C stops it. It stops at the end of
  the input or at a Ctrl+Z. MORE counts long lines that wrap, and expands
  tabs to every eighth column. It takes the screen's number of lines from
  the display driver when it can (25 otherwise). The keys come from the
  keyboard, so MORE works at the end of a pipe.
