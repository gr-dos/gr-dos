Topic: HELP
Summary: Shows help on commands and topics
Origin: GR-DOS
Group: command
Files: HELP.EXE

Syntax
  HELP [topic]

  topic        A command (XCOPY, DIR), a CONFIG.SYS command (FILES), or a
               guide (START). An extension is dropped when there is no
               topic with it: HELP XCOPY.EXE is HELP XCOPY. Upper or lower
               case.

Examples
  HELP
    Lists the topics, by group.
  HELP XCOPY
    Shows how to use XCOPY.
  HELP DIR > PRN
    Prints the help on DIR.

Exit status
  0  The help was shown.
  1  There is no such topic.
  2  GRDOS.HLP was not found.
  3  A bad parameter (more than one, or one starting with /).

Notes
  On the screen HELP stops after each screenful: any key goes on, Q or
  Esc stops. Its output redirected to a file, a printer or a pipe is not
  paged. The help is in the file GRDOS.HLP, which HELP looks for in its
  own directory, then in the current directory, then in each directory
  of the PATH.
